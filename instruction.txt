--------------------------------------------------------------------------------
1. CẤU HÌNH DATABASE (Chỉ thêm 1 bảng mới, không đổi cấu trúc bảng cũ)
--------------------------------------------------------------------------------
Hệ thống sử dụng PostgreSQL với extension `pgvector` để lưu trữ vector ngữ nghĩa.

- Bước 1.1: Kích hoạt extension pgvector trên database:
  CREATE EXTENSION IF NOT EXISTS vector;

- Bước 1.2: Chạy migration tạo bảng lưu trữ vector `book_embeddings`:
  (Sử dụng file Alembic migration đính kèm trong thư mục `alembic/` hoặc chạy script SQL):

  CREATE TABLE IF NOT EXISTS book_embeddings (
      book_id INT PRIMARY KEY,
      content TEXT NOT NULL,
      embedding VECTOR(384) NOT NULL,
      model_name VARCHAR(100) NOT NULL,
      embedding_dimension INT NOT NULL,
      content_hash VARCHAR(64) NOT NULL,
      created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP,
      updated_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
  );

  CREATE INDEX IF NOT EXISTS ix_book_embeddings_hnsw 
  ON book_embeddings USING hnsw (embedding vector_cosine_ops);

2. NỐI DỮ LIỆU SÁCH CỦA QUÝ KHÁCH VÀO AI (Data Adapter)
--------------------------------------------------------------------------------
Vị trí file: `app/ai/repositories/book_provider.py`

Quý khách chỉ cần thay thế phần mock data hiện tại bằng truy vấn SELECT từ bảng 
sách thật của hệ thống và map về các trường chuẩn sau:

- `book_id`    : ID định danh duy nhất của sách (int)
- `title`      : Tiêu đề sách (str)
- `author`     : Tác giả (str)
- `category`   : Thể loại / Danh mục (str)
- `publisher`  : Nhà xuất bản (str)
- `description`: Mô tả nội dung sách (str)
- `isbn`       : Mã ISBN (str)

Ví dụ code trong `book_provider.py`:
```python
async def get_all_books(self) -> List[Dict[str, Any]]:
    # Truy vấn từ bảng sách thực tế của hệ thống:
    stmt = select(BookModel)
    result = await self.session.execute(stmt)
    books = result.scalars().all()
    
    return [
        {
            "book_id": b.id,
            "title": b.title,
            "author": b.author_name,
            "category": b.category_name,
            "publisher": b.publisher_name,
            "description": b.description or "",
            "isbn": b.isbn or "",
        }
        for b in books
    ]

```

3. ĐỒNG BỘ VECTOR CHO SÁCH (Data Lifecycle)

---

* Trường hợp 1: Đồng bộ lần đầu (Batch Sync toàn bộ kho sách)
Chạy lệnh terminal sau để vector hoá toàn bộ catalog hiện có:
$ uv run python -m app.ai.indexing.index_books
*Cơ chế:* Hệ thống sử dụng mã băm SHA-256 (Content Hash), chỉ sinh vector cho sách
mới hoặc sách có nội dung bị chỉnh sửa; tự động bỏ qua (skip) sách không đổi.
* Trường hợp 2: Khi Admin thêm/sửa 1 cuốn sách trên Web, xem ví dụ bên dưới:
Gắn lệnh vector hoá ngầm qua FastAPI `BackgroundTasks` để không làm chậm response:
```python
from app.ai.services.indexing_service import BookIndexingService

@router.post("/admin/books")
async def create_book(book_data, background_tasks: BackgroundTasks, session: AsyncSession = Depends(get_db)):
    new_book = await book_service.create(session, book_data)

    # Kích hoạt AI tạo vector chạy nền:
    indexing_service = BookIndexingService(session)
    background_tasks.add_task(indexing_service.index_single_book, new_book.id)

    return new_book

```

4. SỬ DỤNG CÁC API CỦA MODULE AI

---

Tất cả endpoint đều hỗ trợ Swagger UI trực quan tại: http://localhost:8000/docs

1. AI Search (Tìm kiếm ngữ nghĩa + từ khóa):
* Method: POST /api/v1/ai/search
* Body mẫu:
{
"query": "sách học lập trình cho người mới bắt đầu",
"mode": "semantic",  // hoặc "hybrid", "keyword"
"limit": 5
}


2. AI Recommendation (Gợi ý sách tương đồng / cá nhân hoá):
* Method: POST /api/v1/ai/recommendations
* Không yêu cầu token. Backend chỉ cần gửi mảng ID sách:
{
"book_ids": [101, 103],  // ID các cuốn sách user đã mượn hoặc đang xem
"limit": 5
}
* Trường hợp người dùng mới chưa mượn gì: truyền `"book_ids": []`,
hệ thống tự động trả về các cuốn sách phổ biến nhất.
