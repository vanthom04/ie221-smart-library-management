I. NGUYÊN LÝ HOẠT ĐỘNG CỦA INDEXING SERVICE
======================================================================
- Khi sách mới được thêm/sửa, sách chưa có vector embedding trong bảng
  `book_embeddings` thì Semantic Search chưa tìm thấy được ngay.
- Thay vì tính vector trực tiếp trong mỗi request tìm kiếm (gây nghẽn API),
  hệ thống xử lý thông qua Indexing Service theo 2 cách:
  1. Single Book Indexing: Dùng cho Event-Driven / BackgroundTasks khi 
     thủ thư Thêm/Sửa một cuốn sách cụ thể.
  2. Batch Indexing: Quét toàn bộ kho sách, dùng thuật toán SHA-256 Content
     Hash để tự động bỏ qua (skip) các sách không thay đổi nội dung,
     chỉ sinh vector cho sách mới hoặc sách có sửa đổi.

II. MÃ NGUỒN CẦN BỔ SUNG VÀO DỰ ÁN
======================================================================

----------------------------------------------------------------------
BỔ SUNG VÀO CODE: app/ai/router.py hoặc các router khác tương tự
----------------------------------------------------------------------
a) Bổ sung imports:
from app.ai.schemas import IndexingRequest, IndexingResponse
from app.ai.services.indexing_service import BookIndexingService

b) Thêm Dependency Provider:
def get_indexing_service(session: AsyncSession = Depends(get_db_session)) -> BookIndexingService:
    return BookIndexingService(session)

c) Thêm Endpoint vào Router:
@router.post(
    "/internal/index-books",
    response_model=IndexingResponse,
    status_code=status.HTTP_200_OK,
    summary="[Internal/Admin] Sync Book Embeddings",
    description="Vector hoá sách vào CSDL. Truyền book_id để index đơn lẻ hoặc bỏ trống để quét toàn bộ catalog.",
)
async def trigger_book_indexing(
    payload: Optional[IndexingRequest] = None,
    indexing_service: BookIndexingService = Depends(get_indexing_service),
) -> IndexingResponse:
    target_book_id = payload.book_id if payload else None

    if target_book_id is not None:
        # Nhánh 1: Index 1 cuốn sách cụ thể
        res = await indexing_service.index_single_book(target_book_id)
        return IndexingResponse(
            message=f"Indexing job finished for book {target_book_id}",
            details=res,
        )
    else:
        # Nhánh 2: Quét toàn bộ catalog
        stats = await indexing_service.index_all_books()
        return IndexingResponse(
            message="Batch indexing job finished successfully.",
            details=stats,
        )

     curl -X POST "http://localhost:8000/api/v1/ai/internal/index-books" \
          -H "Content-Type: application/json" \
          -d '{}'
   - Kết quả mong đợi lần 1:
     {
       "message": "Batch indexing job finished successfully.",
       "details": {
         "total_checked": 24,
         "indexed": 24,
         "skipped": 0
       }
     }
   - Bấm Execute LẦN 2 để kiểm tra tính năng Content Hash Skip:
     {
       "message": "Batch indexing job finished successfully.",
       "details": {
         "total_checked": 24,
         "indexed": 0,
         "skipped": 24
       }
     }

4. TEST CASE 2: INDEX 1 CUỐN SÁCH DUY NHẤT (SINGLE BOOK)
   - Chạy qua cURL:
     curl -X POST "http://localhost:8000/api/v1/ai/internal/index-books" \
          -H "Content-Type: application/json" \
          -d '{"book_id": 101}'
   - Kết quả mong đợi:
     {
       "message": "Indexing job finished for book 101",
       "details": {
         "status": "skipped",
         "message": "Book ID 101 unchanged."

     }

IV. HƯỚNG DẪN BÀN GIAO CHO TEAM BACKEND (Code Template)
======================================================================
Gửi đoạn hướng dẫn sau cho team Backend để họ móc nối vào sự kiện tạo sách:

----------------------------------------------------------------------
TEMPLATE CHO TEAM BE: GẮN VÀO ROUTER TẠO / CẬP NHẬT SÁCH
----------------------------------------------------------------------
from fastapi import APIRouter, BackgroundTasks, Depends
from sqlalchemy.ext.asyncio import AsyncSession
from app.core.database import get_db_session
from app.ai.services.indexing_service import BookIndexingService

router = APIRouter()

@router.post("/admin/books")
async def create_book(
    book_in: CreateBookSchema,
    background_tasks: BackgroundTasks,
    session: AsyncSession = Depends(get_db_session),
):
    # 1. Team BE lưu sách vào CSDL như bình thường
    new_book = await crud_books.create(session, book_in)

    # 2. Đẩy tác vụ tính Vector sang BackgroundTask (không gây chậm API tạo sách)
    indexing_service = BookIndexingService(session)
    background_tasks.add_task(indexing_service.index_single_book, new_book.id)

    return new_book
