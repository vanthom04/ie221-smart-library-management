Ở thư mục dự án, mở terminal:

# 1. Khởi tạo môi trường uv
uv sync

# 2. Khởi tạo cấu trúc bảng book_embeddings
uv run alembic upgrade head

# 3. Tính toán và lưu trữ embedding offline cho 24 cuốn sách
uv run python -m app.ai.indexing.index_books

# 4. Khởi chạy FastAPI Server
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

### 
Test thử các API, nếu kết quả trả về của AI search bị lỗi (chỉ trả về 1 kq, kq không liên quan,...) thì dùng lệnh sau, để xóa index IVFFlat trong PostgreSQL:
sudo -u postgres psql -d library_ai_dev -c "DROP INDEX IF EXISTS ix_book_embeddings_vector;"
###

# 5. Chạy test suite
uv run pytest tests/ -v
